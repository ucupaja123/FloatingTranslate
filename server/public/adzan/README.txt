Taruh file adzan (.mp3 / .ogg / .m4a / .wav) di folder ini.

- Nama file = nama muadzin, contoh: makkah.mp3, madinah.mp3, alafasy.mp3, aqsa.mp3
  (tanda - atau _ otomatis jadi spasi, huruf depan jadi kapital).
- Awalan "subuh-" khusus adzan Subuh, contoh: subuh-makkah.mp3
  (adzan Subuh punya tambahan "Ash-shalatu khairum minan-naum").
  Kalau tidak ada file berawalan subuh-, Subuh memakai file biasa.
- Suara dirotasi: tiap hari dan tiap waktu shalat beda muadzin
  (butuh minimal 2 file; makin banyak file makin bervariasi).
- Muat ulang halaman setelah menambah file. Cek lewat tombol "Tes adzan" di tab Sholat.
